========================================
MyFNG - Hostinger Upload Instructions
========================================

🚀 QUICK START:

1. LOGIN to Hostinger
   - Go to https://hostinger.com
   - Login to your account

2. OPEN File Manager
   - Click "File Manager" button
   - Navigate to "public_html" folder

3. UPLOAD FILES
   - Upload hostinger-deployment.zip
   - Right-click → Extract
   - Move all files to public_html root

   OR upload files directly:
   - Upload ALL files from this folder
   - Make sure .htaccess is uploaded

4. VISIT YOUR DOMAIN
   - Go to yourdomain.com
   - You should see the MyFNG homepage!

========================================
TROUBLESHOOTING:
========================================

Problem: 404 errors on page refresh
Solution: Make sure .htaccess is uploaded and
          mod_rewrite is enabled on your hosting

Problem: Styles not loading
Solution: Check if _next folder uploaded correctly

Problem: Images not showing  
Solution: Verify all files in _next/static uploaded

Problem: Login not working
Solution: Check browser console for errors
          Verify Supabase connection

Problem: Slow loading
Solution: Enable HTTPS and compression in cPanel
