## ⚠️ COMMON ISSUES & FIXES

### Issue 1: 404 on page refresh
**Problem:** Pages show 404 when refreshed  
**Solution:** Make sure .htaccess is uploaded  
**Fix:** Check mod_rewrite is enabled in cPanel

### Issue 2: Styles not loading
**Problem:** Page has no styles, looks broken  
**Solution:** Check if _next folder uploaded  
**Fix:** Re-upload _next folder completely

### Issue 3: Slow loading
**Problem:** Pages take 5+ seconds to load  
**Solution:** Enable compression & caching  
**Fix:** Check .htaccess is active

### Issue 4: Login not working
**Problem:** Can't login, errors in console  
**Solution:** Check Supabase connection  
**Fix:** Verify Supabase project is active

### Issue 5: Images broken
**Problem:** Images show broken icon  
**Solution:** Check _next/static/media folder  
**Fix:** Re-upload media files
